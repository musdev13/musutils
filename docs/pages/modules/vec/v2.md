# vec::v2

Pagination and JSON table rendering, second generation.

## Enable

```toml
[dependencies]
musutils = { git = "https://github.com/musdev13/musutils", features = ["vec-v2"] }
```

`vec-v2` has no inter-module dependencies.

When `vec-v2` is enabled, its public items are re-exported at `musutils::vec::*`:

```rust
use musutils::vec::{get_page, page, json_as_table, print_json_as_table, PageError, TableError};
```

## Purpose

`vec::v2` reworks the two v1 helpers:

- Pagination gets a **1-based** variant (`page`) that returns a typed `Result`, alongside the original **0-based** `get_page`.
- Table rendering gets a string-returning, layout-aware `json_as_table` that works out column widths from the data, plus the original `print_json_as_table` re-implemented on top of it.

## Pagination

### `get_page`

```rust
pub fn get_page<T: Clone>(items: &[T], page: u32, count: u32) -> Vec<T>
```

Same as [`vec::v1::get_page`](v1.md#get_page) — **0-based** page numbering, `count` items per page. Elements are `clone()`d.

```rust
use musutils::vec::get_page;

let v = vec![1, 2, 3, 4, 5];
assert_eq!(get_page(&v, 0, 2), vec![1, 2]);
assert_eq!(get_page(&v, 1, 2), vec![3, 4]);
```

Differences from v1: the multiplication `page * count` uses `saturating_mul` before the cast to `usize`, so `get_page(&v, u32::MAX, u32::MAX)` returns an empty slice instead of relying on wrapping arithmetic. Empty pages, out-of-range pages, and `count == 0` return an empty `Vec`.

### `page`

```rust
pub fn page<T: Clone>(items: &[T], page: u32, per_page: u32) -> Result<Vec<T>, PageError>
```

**1-based** pagination with typed errors.

- `page == 0` → `Ok(Vec::new())` (empty result). Pages are numbered starting from 1.
- `per_page == 0` → `Err(PageError::ZeroPerPage)`.
- Otherwise → `Ok(items.iter().skip((page - 1) * per_page).take(per_page).cloned().collect())`.
- The skip amount uses `saturating_mul`, so extremely large `page` / `per_page` values produce an empty result rather than a panic.
- Pages past the end produce an empty `Vec`.

```rust
use musutils::vec::page;

let v = vec![1, 2, 3, 4, 5];
assert_eq!(page(&v, 1, 2).unwrap(), vec![1, 2]);
assert_eq!(page(&v, 2, 2).unwrap(), vec![3, 4]);
assert_eq!(page(&v, 3, 2).unwrap(), vec![5]);
assert!(page(&v, 0, 2).unwrap().is_empty());
assert!(page(&v, 1, 0).is_err());
```

### `PageError`

```rust
pub enum PageError {
    ZeroPerPage,
}
```

Implements `Debug`, `Display`, `Error`. Only one variant exists: `ZeroPerPage`, returned by `page` when `per_page == 0`.

```rust
use musutils::vec::{page, PageError};

let err = page(&[1, 2, 3], 1, 0).unwrap_err();
assert!(matches!(err, PageError::ZeroPerPage));
```

## Table rendering

### `json_as_table`

```rust
pub fn json_as_table(json_vec: &[Value]) -> Result<String, TableError>
```

Renders a vector of JSON objects as a text table and returns it as a `String`.

Column discovery:

- The **union** of keys across **all** objects is collected, in first-encounter order across the slice.
- Non-object elements are ignored for column discovery and row rendering.

Column width:

- The width of a column is the maximum of:
  - the length of its header (in `chars`, not bytes — Unicode-safe),
  - the length of each cell value rendered as a string.
- The rendered cell for a missing key is `"N/A"`, which participates in width computation.

Output layout:

- Header row: headers padded to column width, joined with `" | "`.
- Separator row: `"-"` repeated to the total header width (in `chars`).
- One row per object, cells padded to column width, joined with `" | "`.
- A second separator row identical to the first.
- No trailing newline after the final separator.

Cell rendering:

- `Value::String(s)` → `s` verbatim (no surrounding quotes).
- Any other `Value` → its `serde_json::Display` output (`null`, `true`, numbers, arrays / objects as JSON).

Errors:

- `TableError::Empty` when `json_vec` is empty.
- `TableError::NoFields` when no element is an object or all objects are empty.

```rust
use musutils::vec::json_as_table;
use serde_json::json;

let data = vec![
    json!({"a": 1, "b": "x"}),
    json!({"a": 22, "b": "yy"}),
];
let table = json_as_table(&data).unwrap();
println!("{table}");
```

Unicode keys and values are measured in characters, so the separator line matches the header width even when the header contains non-ASCII text:

```rust
use musutils::vec::json_as_table;
use serde_json::json;

let data = vec![json!({"имя": "значение"})];
let table = json_as_table(&data).unwrap();
let mut lines = table.lines();
let header = lines.next().unwrap();
let sep = lines.next().unwrap();
assert_eq!(header.chars().count(), sep.chars().count());
```

### `print_json_as_table`

```rust
pub fn print_json_as_table(json_vec: &[Value])
```

Prints the same table that `json_as_table` would return, followed by a newline (via `println!`). On error, prints one of the v1 messages:

- `No data to display.` for `TableError::Empty`,
- `No fields to display.` for `TableError::NoFields`.

```rust
use musutils::vec::print_json_as_table;
use serde_json::json;

print_json_as_table(&[json!({"a": 1}), json!({"a": 2})]);
```

### `TableError`

```rust
pub enum TableError {
    Empty,
    NoFields,
}
```

Implements `Debug`, `Display`, `Error`.

- `Empty` — returned when the input slice is empty.
- `NoFields` — returned when no object with at least one key is present.

```rust
use musutils::vec::{json_as_table, TableError};

assert!(matches!(json_as_table(&[]), Err(TableError::Empty)));
assert!(matches!(json_as_table(&[serde_json::json!("x")]), Err(TableError::NoFields)));
```

## Differences from v1

| Aspect | v1 | v2 |
|---|---|---|
| `get_page` | 0-based | 0-based, `saturating_mul` for the index computation |
| 1-based pagination | — | `page` + `PageError` |
| Table rendering | `print_json_as_table` prints, fixed width | `json_as_table -> Result<String, _>` + `print_json_as_table` |
| Column set | First object only | Union of all objects |
| Column width | Fixed 25 | Computed per column |
| Separator width | Byte length of the header line | Character count of the header line |
| Errors | None | `PageError`, `TableError` |
